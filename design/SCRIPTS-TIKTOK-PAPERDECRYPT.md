# Scripts vidéo Paperdecrypt (TikTok, Reels, Shorts)

Les 6 vidéos de la semaine 0 du plan `LANCEMENT-PAPERDECRYPT.md` (n° 1, 2, 5, 6, 7, 8). Format vertical 9:16, 20 à 25 secondes, sous-titres incrustés (beaucoup regardent sans le son).

**Règles** : écran filmé avec le bouton « Voir un exemple » (jamais de vrai courrier, de vraie fiche de paie ni de vrai nom) ; pas de prix, pas de lien dans la vidéo ; aucune mention d'intelligence artificielle ; pas de promesse de résultat ; « gratuit pour commencer, options Premium » si on parle du prix. Voix off calme et directe, tutoiement. Musique libre de droits, volume bas.

**Matériel** : un téléphone avec l'application installée (écran d'accueil), un fond uni, la lumière d'une fenêtre. Enregistrer l'écran du téléphone (enregistrement d'écran intégré) puis ajouter les textes dans CapCut. Dernier plan identique sur toutes les vidéos : l'icône de l'application + « Paperdecrypt · lien en bio » (2 secondes).

## Tourner efficacement (une demi-journée pour les 6)
1. Préparer 3 papiers fictifs imprimés (fiche de paie d'exemple, courrier, ticket) et les photographier une fois pour les scènes « papier ».
2. Enregistrer tous les écrans d'un coup avec l'enregistrement d'écran, en répétant chaque geste deux fois (garder la meilleure prise).
3. Monter dans CapCut : textes en gros, 2 lignes maximum, contraste fort, sous-titres automatiques relus.
4. Exporter en 1080×1920 sans filigrane ; garder les sous-titres dans la zone centrale (éviter le bas, masqué par la légende).
5. Programmer via Metricool une fois le compte créé : 3 vidéos la semaine 1, à 12 h 15 et 19 h 30 (à ajuster selon les statistiques).
