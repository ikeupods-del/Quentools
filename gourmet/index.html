🆓 Tuto : activer le Chef IA gratuitement
  1. Ouvrez aistudio.google.com/apikey
  2. Connectez-vous avec votre compte Google.
  3. Cliquez sur Créer une clé API (Create API key) et choisissez ou créez un projet.
  4. Copiez la clé (elle commence par AIza).
  5. Collez-la dans le champ juste en dessous, puis appuyez sur OK.
  6. Allez dans IngréMatch, puis 🤖 Chef IA.

L'offre gratuite de Google ne demande pas de carte bancaire, mais elle a des limites d'usage qui peuvent changer. Ne partagez jamais votre clé.
