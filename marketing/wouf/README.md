# Kit Instagram de Wouf

- `images/` : 29 visuels prêts à publier (posts 1080×1350, carrousels, stories 1080×1920, photo de profil, couvertures « à la une »).
- `kit.html` : le guide (bio, légendes à copier, Reels, calendrier de 30 jours, méthode de croissance).
- `generate.js` : régénère tous les visuels à partir de la vraie app (à relancer après une mise à jour visible de Wouf) :
  `node marketing/wouf/generate.js` (depuis la racine du dépôt, après `cd wouf && npm install`).

Règles : aucun faux avis, aucun faux chiffre, pas de « n°1 », pas de partenariat SPA (non affilié), pas de prix Wouf+ tant que la vente n'est pas ouverte.
