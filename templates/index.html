Bon à savoir sur les démonstrations

Dans les démonstrations, les paiements, les e-mails et les comptes sont simulés et les données restent dans votre navigateur. Les entreprises et les prix affichés y sont fictifs. Rendre ces fonctions réelles (paiement, réservations enregistrées, e-mails) est une option sur devis.
